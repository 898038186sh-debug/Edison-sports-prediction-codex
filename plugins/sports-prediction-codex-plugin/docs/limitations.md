# Limitations

## No live-data guarantee

This plugin does not automatically provide live sports data. If the runtime environment cannot access fresh information, the report must state that limitation.

## No assured accuracy

Sports predictions are probabilistic. Injuries, weather, tactical changes, referee decisions, randomness, and late-breaking news can all change outcomes.

## Injury and lineup uncertainty

Injury reports and lineups may change close to game time. The skill should explicitly identify unavailable or uncertain information.

## Data quality dependency

The quality of the output depends on the quality and freshness of the input data.

## League-specific differences

Different sports and leagues require different assumptions. Soccer has draws; NBA, MLB, NFL, and NHL typically use two-outcome win probabilities.

## Market movement risk

Odds can move quickly and may reflect information not visible in the prompt. Odds context should not be framed as a betting recommendation.

## Responsible use

This plugin is for educational and analytical workflows. It is not betting advice, financial advice, investment advice, or a system for assured profit.
