# Methodology

This skill uses a structured, uncertainty-aware workflow for sports match analysis.

## 1. Start with match context

Identify the teams, league, venue, date, time, and competition format. If any of these are unknown, state that clearly.

## 2. Check data freshness

Before making any prediction, assess whether current data is available. Important data includes injuries, lineups, recent form, schedule context, weather where relevant, and odds movement where available.

If current data is unavailable, the output must be framed as a workflow example rather than a live prediction.

## 3. Review recent form

Look at recent team performance, attacking and defensive trends, and home/away patterns. Avoid overreacting to a single recent result.

## 4. Review injuries and availability

Player availability can change predictions substantially. Confirmed absences, doubtful players, rest decisions, and likely lineups should be separated from assumptions.

## 5. Use head-to-head carefully

Head-to-head records can provide context, but they should not dominate the analysis. Rosters, coaches, tactics, and conditions change.

## 6. Consider schedule and fatigue

Travel, rest days, fixture congestion, altitude, back-to-back games, and recent extra-time games can affect performance.

## 7. Consider tactical or style matchup

Assess how the teams' styles interact. Consider tempo, pressing, possession, transition defense, key player dependencies, and matchup weaknesses.

## 8. Treat odds as market context

Odds may reflect market expectations, news, liquidity, and public behavior. They are not recommendations. If odds are used, include implied probability and note limitations.

## 9. Use probabilities, not absolute predictions

The skill should produce probability estimates and confidence levels. This helps communicate uncertainty and avoids misleading claims.

## 10. End with responsible-use language

Every report should remind users that the analysis is educational, not betting or financial advice.
