# Example Prompts

## Soccer / football

```text
Use the sports-prediction skill to analyze Arsenal vs Chelsea and produce a transparent pre-match prediction report.
```

```text
Use the sports-prediction skill to analyze Real Madrid vs Barcelona. Include data freshness, injuries, tactical factors, probabilities, and uncertainty.
```

## NBA

```text
Use the sports-prediction skill to compare Lakers vs Celtics, including team form, injury uncertainty, confidence level, and risk notes.
```

## MLB

```text
Use the sports-prediction skill to analyze Yankees vs Red Sox. Include starting pitcher uncertainty, bullpen context, and risk notes if data is available.
```

## NFL

```text
Use the sports-prediction skill to analyze Chiefs vs Bills. Include rest days, injury context, matchup style, and confidence level.
```

## General pre-match analysis

```text
Use the sports-prediction skill to create a non-betting educational analysis for an upcoming match.
```

## Match comparison

```text
Use the sports-prediction skill to compare both teams' recent form and produce probability estimates with transparent uncertainty notes.
```

## Uncertainty-first prediction

```text
Use the sports-prediction skill, but start by listing missing data and uncertainty before giving any probability estimate.
```

## Educational report
