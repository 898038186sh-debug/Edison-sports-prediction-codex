# Security Policy

## Sensitive data

Do not commit:

- API keys
- Tokens
- Passwords
- Private keys
- Paid/private sports data feeds unless licensing allows redistribution
- Betting account data
- Personal financial information

## Reporting issues

Open a GitHub issue for security concerns that do not expose private information. If the repository owner provides a private contact method, use that for sensitive reports.

## Data source licensing

Only include data sources that are allowed by their licenses or terms. Do not copy paid datasets into this repository unless redistribution is explicitly permitted.
