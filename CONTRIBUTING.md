# Contributing

Thanks for considering a contribution.

## Good contributions

Helpful contributions include:

- Improving the skill workflow
- Making output structure clearer
- Adding responsible examples for more sports or leagues
- Improving documentation
- Fixing JSON or packaging issues
- Adding validation scripts

## Required standards

All contributions must follow these rules:

- Do not add betting advice language.
- Do not add claims of certain outcomes.
- Do not add fake backtests or fake performance claims.
- Do not fabricate data sources.
- Preserve responsible-use disclaimers.
- Separate verified data from assumptions.
- Update README/docs when skill behavior changes.

## Pull request checklist

Before opening a PR:

- Validate JSON files.
- Check for secrets or API keys.
- Ensure examples are fictional or clearly sourced.
- Keep the project educational and transparent.
