# v0.1.2 - Rename public display to 体育预测

This release updates the public-facing name and metadata so the plugin appears as 体育预测 instead of using personal branding.

## What changed

- Renamed the marketplace and plugin display name to 体育预测.
- Removed personal branding from plugin author and developer metadata.
- Kept installation links pointed at the current repository URL so they remain valid until the GitHub repository itself is renamed.
- Kept the internal skill id as `sports-prediction` because Codex skill names use lowercase hyphen-case identifiers.

## Positioning

体育预测 is for educational and analytical sports workflows. It is not betting advice, financial advice, a gambling recommendation system, or a guaranteed prediction tool.
