# v0.1.0 - Public release of 体育预测

This is the first public release of 体育预测.

## What is included

- Codex repo marketplace configuration at `.agents/plugins/marketplace.json`
- Plugin manifest at `plugins/sports-prediction-codex-plugin/.codex-plugin/plugin.json`
- Sports prediction skill at `plugins/sports-prediction-codex-plugin/skills/sports-prediction/SKILL.md`
- Documentation for methodology, limitations, responsible use, examples, security, and contribution
- GitHub issue templates and validation workflow
- Lightweight repository validator at `scripts/validate_repo.py`

## Positioning

This project is for educational and analytical sports workflows. It helps AI agents produce structured pre-match reports with probabilities, confidence levels, uncertainty notes, and responsible-use disclaimers.

It is not betting advice, financial advice, a gambling recommendation system, or a guaranteed prediction tool.
